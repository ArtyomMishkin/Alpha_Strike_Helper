ТЕХНИЧЕСКОЕ ЗАДАНИЕ
Разработка веб-приложения для управления отрядами боевых мехов в настольной игре Alpha Strike
1. Основание для разработки
Разработка веб-приложения обусловлена необходимостью упрощения процесса формирования и управления отрядами боевых мехов (Lance и Star) в настольной игре BattleTech: Alpha Strike, а также автоматизации расчета характеристик и подготовки распечатываемых карточек для игры.

2. Назначение разработки
Создание программного комплекса для управления коллекцией боевых мехов, формирования тактических отрядов (Lance и Star) с автоматическим расчетом характеристик и экспорта данных для печати.

3. Цели разработки
Создание удобного интерфейса для управления базой данных боевых мехов

Реализация системы формирования отрядов с учетом тактических ограничений (3-4 меха в Lance, 3-5 мехов в Star)

Разработка модуля автоматического расчета характеристик отрядов (общий PV, броня, структура)

Создание системы экспорта данных для печати карточек отрядов

Реализация многопользовательской системы с разграничением доступа

4. Требования к функциональным характеристикам
4.1. Система управления картами мехов
Просмотр каталога доступных мехов с пагинацией (50 карт на страницу)

Фильтрация по характеристикам: Type (Light/Medium/Heavy/Assault), Role (Scout/Skirmisher/Brawler/Sniper), Point Value (PV)

Поиск по названию меха

Отображение полных характеристик карты: название, модель, тип, размер, движение, TMM, PV, броня, структура, урон, способности

4.2. Система формирования Lance (Inner Sphere)
Создание отрядов из 3-4 мехов

Указание названия, описания и фракции отряда

Автоматический расчет суммарных характеристик:

Общий Point Value (PV)

Суммарная броня

Суммарная структура

Визуальное отображение состава отряда с позициями (1-4)

Редактирование существующих отрядов

Удаление отрядов

4.3. Система формирования Star (Clan)
Создание отрядов из 3-5 мехов

Указание названия, описания и фракции отряда

Автоматический расчет суммарных характеристик аналогично Lance

Визуальное отображение состава с позициями (1-5)

Редактирование существующих звезд

Удаление звезд

4.4. Модуль экспорта и печати
Генерация HTML-документов для печати Lance/Star

Табличное представление характеристик всех мехов отряда

Отображение сводной информации: название отряда, фракция, общий PV, общая броня

Автоматический вызов диалога печати браузера

4.5. Система аутентификации
Регистрация пользователей

Авторизация с использованием JWT-токенов

Разграничение доступа: каждый пользователь видит только свои отряды

Хранение токенов в localStorage

5. Требования к надежности
Гарантированное сохранение данных в PostgreSQL

Транзакционная целостность при создании/редактировании отрядов

Восстановление сессии пользователя при перезагрузке страницы

Обработка ошибок сети с информированием пользователя

Валидация данных на стороне клиента и сервера

6. Условия эксплуатации
Веб-доступ через стандартные браузеры (Chrome, Firefox, Safari, Edge)

Работа в локальной сети или через интернет

Поддержка адаптивного дизайна для различных разрешений экрана

Минимальные требования: браузер с поддержкой ES6 и Fetch API

7. Требования к составу и параметрам технических средств
Серверная часть:

Язык программирования: Go 1.20+

Веб-фреймворк: Fiber v2

СУБД: PostgreSQL 14+

Библиотеки:

github.com/gofiber/fiber/v2

github.com/lib/pq (драйвер PostgreSQL)

github.com/golang-jwt/jwt/v5 (JWT аутентификация)

golang.org/x/crypto (bcrypt для паролей)

Клиентская часть:

HTML5, CSS3, JavaScript (ES6+)

Без использования внешних фреймворков (Vanilla JS)

Адаптивный дизайн с использованием Flexbox/Grid

Требования к серверу:

ОС: Linux (Ubuntu 20.04+ / Debian 11+) или Windows Server 2019+

RAM: минимум 1 ГБ

Диск: 10 ГБ свободного места

Сеть: порт 8080 для API
